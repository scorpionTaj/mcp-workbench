═══════════════════════════════════════════════════════════════════════════════
 1. SHIPPED
═══════════════════════════════════════════════════════════════════════════════

FOUNDATION ✅
├── Next.js 16 (App Router, proxy.ts), React 19, TypeScript, Bun
├── PostgreSQL + pgvector with Drizzle ORM; migrations 0000–0019
│   (bun run db:migrate waits for Postgres and reports the real error)
├── Better Auth: email/password, optional GitHub/Google, admin via ADMIN_EMAILS
├── Every record scoped to its owner; API keys and MCP headers encrypted
├── CSRF origin check on mutating API calls; SSRF guard on provider URLs
├── Rate limiting: per user on chat, compare, Studio and uploads; per IP on
│   sign-in and sign-up; per API key; per link on share passwords (in memory,
│   per instance; RATE_LIMIT=off disables)
├── Personal API keys (Settings): `Authorization: Bearer mwb_…`, shown once,
│   SHA-256 hashed, revocable, last-used time; never admin, can't manage keys
├── Private uploads, served only to their owner
├── Docker (Dockerfile + compose with pgvector, healthcheck), backup/restore scripts
└── CI: frozen install, typecheck, lint, tests (28 files), production build

PROVIDERS & MODELS ✅
├── Chat: OpenAI, Anthropic, Google, Groq, OpenRouter, Together, Mistral,
│   Cohere, Hugging Face, Ollama, LM Studio, any OpenAI-compatible
├── /providers: keys, base URLs, enable/disable, live status
├── /models: discovery, filters, capability detection (vision, reasoning,
│   embeddings, image, audio), per-model overrides (reasoning, price)
└── Server-wide fallback keys for every keyed provider (OPENAI_API_KEY, …)

CHAT ✅
├── Streaming on the Vercel AI SDK; stop, retry after an error
├── Per-chat model, system prompt and sampling settings (saved with the chat)
├── Regenerate the latest reply; edit a sent message and continue from it
├── Image, PDF and text attachments
├── Slash commands with $ARGUMENTS and $1…$9
├── Reactions and annotations on messages
├── History search over titles and message text, with highlighted snippets;
│   recent searches and suggestions in the history and the ⌘K palette
├── Organization: pin, archive, folders and tags, with folder/tag filters
├── Export as JSON or CSV
├── Inspector: every tool call with input, output and timing
├── Branching: start a new chat from any assistant reply
└── Sharing: public read-only link (/share/<token>), revocable, with optional
    expiry and password (scrypt; a signed httpOnly cookie per link once
    unlocked); attachments, system prompt and token counts stay private;
    "Continue this chat" copies it into the viewer's workspace

AGENTS, SKILLS & PLUGINS ✅
├── Agents: instructions, default model, temperature, step budget, starter
│   prompts, attached MCP servers, skills and knowledge bases; six built-ins;
│   shareable without exposing tools, keys or documents
├── Agent Skills (SKILL.md, progressive disclosure), written in-app or
│   imported from GitHub
└── Claude Code plugins and marketplaces from GitHub: install, update,
    disable, uninstall as one unit

SCHEDULED AGENTS ✅
├── /schedules: cron in any time zone, presets, run now, pause, edit, delete
├── Each run lands in a new chat; runs at least 15 minutes apart
├── In-process scheduler (instrumentation.ts); safe with several instances;
│   SCHEDULER=off disables it on an instance
├── Unattended runs only get tools that never need approval
└── Optional webhook (Slack and Discord messages, or JSON) and/or an email to
    the owner when a run finishes (Resend or SMTP; EMAIL_FROM sets the sender)

MCP ✅
├── Remote servers over Streamable HTTP or SSE, encrypted auth headers
├── OAuth sign-in for servers that require it
├── Approval policy per server: never · unless read-only · always; signed approvals
├── Inspector: run tools, read resources, get prompts (/tools)
├── Official MCP Registry browser with one-click add (/registry)
├── Import mcpServers configs from Claude Desktop, Cursor or VS Code
└── stdio bridge (scripts/mcp-bridge.ts) to use local stdio servers

KNOWLEDGE (RAG) ✅
├── PDF, HTML, Markdown, text, code, CSV, JSON, web pages, pasted text, dataset rows
├── Chunking with overlap; embeddings from any provider; pgvector storage
├── Hybrid retrieval: cosine + Postgres full-text, reciprocal rank fusion
├── HNSW indexes for 384/768/1024/1536 dims (3072 as halfvec on pgvector ≥ 0.7)
├── Optional reranking (Cohere, Together)
└── search_knowledge tool with citations; retrieval playground; chunk viewer

STUDIO ✅
├── Image generation (OpenAI, Google Imagen, Together FLUX, compatible servers)
├── Replicate images (FLUX Schnell, FLUX Pro, SDXL): predictions with Prefer: wait,
│   polled up to 60 s, outputs saved as private uploads; Replicate stays out of
│   chat, compare, agent and schedule pickers (it has no chat API)
├── Speech to text (Whisper, GPT-4o transcribe, Groq)
└── Text to speech with voices; private history with download and delete

DATA & ANALYTICS ✅
├── Compare up to four models side by side: first-token time, total time,
│   tokens, tokens/s, cost; word-level diff between two answers; batch
│   prompts (pasted or .txt/.csv) as a prompts × models grid with CSV export;
│   LLM-as-judge scores (1–10 + rationale) with an editable rubric
├── Usage analytics: tokens and cost per day, by model, tool calls (errors,
│   denials), agents; CSV export of per-day and per-model rows for a date range
├── Cost tracking: built-in price table (lib/pricing.ts) with per-model price
│   overrides on /models; each reply's cost is stored when it is saved (older
│   replies and models without a price show —)
├── Datasets: CSV/TSV/Parquet preview with column statistics; add to knowledge
├── Embeddings playground with a similarity heatmap
├── Python notebook in the browser (Pyodide), packages auto-loaded from imports;
│   code and markdown cells, Run All, matplotlib figures shown under the cell
└── Notebooks saved to the account (Open/Save, one-time import of notebooks
    left in localStorage) and .ipynb import/export (nbformat 4)

UI & OPERATIONS ✅
├── HeroUI v3 + Tailwind v4 redesign; light, dark and system themes
├── App shell with a single page scroller; command palette (⌘K)
├── New logo, favicon and app icons
├── /health with admin-only metrics (/api/health/metrics), /feedback with admin review
└── Settings: account, appearance, workspace counts, MCP config import
